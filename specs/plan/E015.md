# Epic Details: E015 — Activity Logging & Visibility

- **Category**: PRODUCT
- **Priority**: P2
- **Source**: {PRD:CAP-010}

## Scope
Implement a size-bounded activity log persisted in SQLite and viewable in the UI. Records check executions, notification dispatches, errors, and system events. Includes filtering, traceback viewing, and rolling retention.

## Traceability & Dependencies
- **Actors**: Operator
- **Key Entities**: ActivityLogEntry (timestamp, level, category, message, device_id, module_name, traceback)
- **Depends on**: E002 (DB), E010 (CheckResult), E004 (UI)
- **Dependency Contracts**: E002 RepositoryBase
- **Depended on by**: None
- **Produces (shared)**: ActivityRepository, activity API routes, LogsPage UI (LogTable, FilterBar, TracebackPanel)
- **Constraints**: Size-bounded, rolling retention

## Acceptance Criteria
- [ ] Activity log migration creates `activity_log` table
- [ ] ActivityRepository with size-bounded insert (auto-prune old entries)
- [ ] GET `/api/v1/activity` with filtering by level/category/date
- [ ] Frontend LogsPage with LogTable, FilterBar, TracebackPanel
- [ ] Check results and notification dispatches automatically logged
- [ ] Tests for retention limits and filtering

- **Description**: Size-bounded activity log with in-UI viewer, filtering, traceback display, rolling retention
- **Actors**: Operator
- **Key Entities**: ActivityLogEntry
- **Depends on Artifacts**: E002 DB, E004 UI
