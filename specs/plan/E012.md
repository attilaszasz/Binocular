# Epic Details: E012 — Manual On-Demand Checks

- **Category**: PRODUCT
- **Priority**: P1
- **Source**: {PRD:CAP-005}

## Scope
Implement manual on-demand check workflows: trigger an immediate check for a single device or bulk-check all devices. Side-by-side comparison of stored vs. latest version in the UI.

## Traceability & Dependencies
- **Actors**: Operator
- **Key Entities**: CheckResult
- **Depends on**: E006 (Device), E010 (CheckService), E004 (UI)
- **Dependency Contracts**: E010 CheckService, E006 Device entity
- **Depended on by**: E014 (triggers notifications)
- **Produces (shared)**: Check API routes, check UI components
- **Constraints**: None

## Acceptance Criteria
- [ ] POST `/api/v1/checks/device/{id}` triggers a single-device check
- [ ] POST `/api/v1/checks/bulk` triggers checks for all devices
- [ ] API returns CheckResult with stored vs. latest version
- [ ] UI displays side-by-side version comparison
- [ ] UI shows loading state during checks
- [ ] Tests for single and bulk check endpoints

## Specify Input
- **Description**: Manual on-demand single and bulk checks with side-by-side version comparison in the UI
- **Actors**: Operator
- **Key Entities**: CheckResult
- **Depends on Artifacts**: E006 Device, E010 CheckService
- **Constraints**: None
