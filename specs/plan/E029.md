# Epic Details: E029 — Official Canon RF Lenses

- **Category**: PRODUCT
- **Priority**: P2
- **Source**: {PRD:CAP-015}{SAD:ADR-0005}{SAD:ADR-0012}

## Scope
Ship an independently selectable official lens module for exact, model-only lookup across Canon Asia English RF and RF-S catalogues. Admit lenses while excluding adapters, extenders, cinema products, and unrelated mounts; discover each product's firmware form action, deduplicate operating-system packages, link the official release page, seed automatically, and distinguish no firmware from lookup or parsing failure.

- [ ] The Canon RF Lenses module is independently selectable, accepts an exact model without a URL, is automatically seeded idempotently, and resolves only classified lens entries from captured RF/RF-S catalogues while rejecting adapters, extenders, cinema products, unrelated mounts, and near-name variants.
- [ ] Captured RF24-105mm F4 L IS USM product, firmware-fragment, and release-detail fixtures reproduce the verified 2026-09-06 observation (`2.0.7`, official detail page `https://asia.canon/en/support/0401117302?model=RF24-105mm+F4L+IS+USM`) and collapse equivalent Windows/macOS packages into one release; the golden value is fixture evidence, not a permanently latest version.

- [ ] Integration tests cover version search and normal check execution, automatic seeding, independent selection from the camera module, shared 30-second Canon-origin pacing across retries/concurrency, and no requests after timeout/cancellation using injected time and captured fixtures.
