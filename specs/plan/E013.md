# Epic Details: E013 — Automated Scheduled Checking

- **Category**: PRODUCT
- **Priority**: P1
- **Source**: {PRD:CAP-004}{SAD:ADR-0007}

## Scope
Implement automated scheduled checking using APScheduler in-process interval jobs. Per-module check frequency, user-configurable per device. Schedules are restart-safe (resume on next interval) and stored in the database.

## Traceability & Dependencies
- **Actors**: None (automated)
- **Key Entities**: Schedule (module_id, interval_hours, last_run, next_run)
- **Depends on**: E010 (CheckService), E007 (modules), E002 (DB)
- **Dependency Contracts**: E010 CheckService, E007 Module entity
- **Depended on by**: E014, E015, E018
- **Produces (shared)**: SchedulerService, Schedule entity, schedule API routes, FrequencyEditor UI component
- **Constraints**: APScheduler 3.x, in-process, restart-safe

## Acceptance Criteria
- [ ] Schedule migration creates `schedules` table with module_id FK
- [ ] APScheduler interval jobs trigger CheckService per module
- [ ] Per-module default frequency configurable via API
- [ ] GET/PUT `/api/v1/schedules` for viewing/editing frequencies
- [ ] Scheduler resumes on app restart at next interval
- [ ] FrequencyEditor component on Modules page
- [ ] Tests for scheduler registration, interval execution
