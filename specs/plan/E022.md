# Epic Details: E022 — Module Upload Progress Feedback

- **Category**: PRODUCT
- **Priority**: P1
- **Source**: {PRD:CAP-003}{SAD:ADR-0011}

## Scope
Implement streaming validation progress updates from the backend (using a FastAPI chunked response streaming newline-delimited JSON events) and update the React frontend upload form component to read from this stream in real-time. This provides visual step-by-step feedback (AST static analysis, runtime verification, saving) during long-running custom module uploads to reassure the operator that the process is active and has not crashed.

## Traceability & Dependencies
- **Actors**: Operator
- **Key Entities**: Module, ValidationResult
- **Depends on**: E007, E009
- **Dependency Contracts**:
  - API: `POST /api/v1/modules` must support chunked streaming responses.
  - Library: Frontend `ModuleUploadForm.tsx` uses standard browser `ReadableStream` reader API.
- **Depended on by**: None
- **Produces (shared)**: None
- **Constraints**:
  - Must not require external task queue infrastructure (Redis, Celery, or background processes).
  - Must remain fully compatible with existing static AST and runtime validator interfaces.

## Acceptance Criteria
- [ ] `POST /api/v1/modules` streams progress events (AST start, AST done, Runtime verification start, Runtime verification done, Database registration start, Saved) as newline-delimited JSON lines.
- [ ] If a validation phase fails, the endpoint streams the final validation failure details as the terminal JSON event and closes the stream with appropriate HTTP status.
- [ ] The React frontend `ModuleUploadForm.tsx` intercepts the stream, decodes the chunks, and updates a step-by-step list of progress checkpoints in the UI.
- [ ] The UI renders intermediate states clearly with appropriate visual indicators (spinners, checkmarks, or error crosses) and maintains support for "Copy for AI" copy-paste helpers upon failure.
- [ ] Unit and integration tests verify that both successful and failed validation streams return correct sequential event logs.

## Specify Input
- **Description**: Implement a streaming response for custom module upload validation in the FastAPI server and adapt the React upload form component to show step-by-step progress details.
- **Actors**: Operator
- **Key Entities**: Module, ValidationResult
- **Depends on Artifacts**: specs/prd.md, specs/sad.md
- **Constraints**: Single-process Monolith, zero external queues or brokers.
