# Epic Details: E030 — Add Device Module Source Link

- **Category**: PRODUCT
- **Priority**: P2
- **Source**: {PRD:CAP-001}{PRD:CAP-002}{SAD:ADR-0013}

## Scope
Surfaces the canonical source page a module scrapes as a clickable link on the Inventory > Add Device form. Extends the module authoring contract with an optional `SOURCE_URL` constant, persists it in a new `modules.source_url` column, returns it through the modules API, and renders it in the form so users can look up the exact model name a module expects.

## Traceability & Dependencies
- **Actors**: Self-hosting operator adding a device; module author declaring a source URL
- **Key Entities**: Module (`source_url`), `SOURCE_URL` contract constant
- **Depends on**: E006, E007, E009
- **Dependency Contracts**: E006 supplies the Add Device form and device-creation flow; E007 supplies the module loader and V1 authoring contract; E009 supplies `/api/v1/modules` and `ModuleResponse`
- **Depended on by**: None
- **Produces (shared)**: `modules.source_url` column (migration 0008), `SOURCE_URL` contract constant, `ModuleResponse.source_url` field, `useModules` frontend module type
- **Constraints**: Optional contract constant with empty default; no change to check execution, scraping, pacing, or detection; absent/empty URL must render no link; backend must pass `mypy --strict`; frontend must pass `tsc` strict

## Acceptance Criteria
- [ ] The V1 module contract supports an optional module-level `SOURCE_URL` string constant; the loader extracts it (empty when absent) without failing modules that omit it, and two-phase validation still accepts modules with or without the constant.
- [ ] A numbered SQL migration adds a nullable `source_url` column to `modules`; the loader path, upload path, and official-module seeder persist each module's declared source URL, and every shipped official module declares its canonical source page.
- [ ] `ModuleResponse` and the modules API surface `source_url`; the Add Device form renders the selected module's source URL as a clickable external link when present, and renders nothing when empty.
- [ ] Existing tests stay green and new coverage verifies source-URL extraction/persistence, API serialization, and the frontend link rendering (present and empty states) with `mypy --strict` and `tsc` strict passing.

## Specify Input
- **Description**: On the Inventory > Add Device form, when a module is selected, show a clickable URL of the webpage that module scrapes so users can look up the exact model name to enter. Add an optional `SOURCE_URL` constant to the module authoring contract, a `modules.source_url` column, extraction/persistence in the loader, upload, and seeder paths, and surface it via the modules API for the form to render.
- **Actors**: Self-hosting operator; module author
- **Key Entities**: Module (`source_url`), `SOURCE_URL` contract constant
- **Depends on Artifacts**: E006 device-creation form; E007 module contract + loader; E009 modules API + `ModuleResponse`
- **Constraints**: Optional constant with empty default; no link when absent/empty; no change to check/scrape behavior; `mypy --strict` and `tsc` strict must pass
