## Acceptance Criteria
- [ ] Every official module explicitly negotiates V2/catalog and enumerates its supported source models independently of inventory, with stable source keys, useful names/aliases/source links, and distinct region/mount/hardware revision wherever compatibility requires them. Captured fixtures establish verified coverage, near-name rejection, and honest empty/partial/structural-failure outcomes.
- [ ] Shared source indexes are reused once per applicable refresh scope; authoritative inline firmware and necessary model-detail requests produce matching validated firmware/no-firmware results without duplicate manufacturer discovery for multiple owned copies. Deterministic request-count/pacing/cancellation tests cover each source's actual request shape, not an assumed one-request catalog.
- [ ] Canon camera/lens modules remain independently selectable and limited to verified Canon Asia English EOS R and RF/RF-S catalogues. Preserve verbatim product links/discovered firmware actions, OS-package release deduplication, official release links, strict 24-hour endpoint expiry/invalidation/single fallback, and the shared 30-second origin timeline. Persist observations separately; no Cinema EOS/EOS R5 C, accessory/unrelated-mount/regional/binary-download expansion or invented positive RF-S release.
- [ ] Automatic protected-module seeding/update preserves module/model UUIDs and saved frequency/pause, linked inventory/installed/history, and honest capability status. Exact uniquely verified compatible legacy matches link safely; ambiguous models stay unresolved, with per-model fallback only if the legacy checker remains exported. Zero-inventory refresh and local model reads work for each official source without deleting referenced missing models.
- [ ] Official module fixtures/integration tests and source/coverage notes pass together with version-aligned working examples and AI Module Kit from E033. Document per-source enumeration/detail expectations and freshness/error semantics; no claim that full catalog completion fits a single Canon model's warm/cold latency, and no live source dependency in mandatory tests.
