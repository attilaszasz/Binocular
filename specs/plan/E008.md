# Epic Details: E008 — Self-Hosted Operability

- **Category**: PRODUCT
- **Priority**: P1
- **Source**: {PRD:CAP-009}{SAD:ADR-0008}{DOD:DDR-002}

## Scope
Implement operational features for self-hosted deployment: zero-config startup with sensible defaults, secrets loading via env vars with `_FILE` Docker-secret pattern, optional basic-auth middleware (off by default), `.env.example` documentation, and BINOCULAR_DB_PATH configuration.

## Traceability & Dependencies
- **Actors**: Operator
- **Key Entities**: None (configuration)
- **Depends on**: E001 (config, app factory), E002 (DB path config)
- **Dependency Contracts**: E001 Pydantic Settings config
- **Depended on by**: E014 (secrets for SMTP/Gotify), E018 (backup config)
- **Produces (shared)**: Secret/_FILE loader, optional basic-auth middleware, .env.example
- **Constraints**: Zero-config startup, optional basic auth off by default

## Acceptance Criteria
- [ ] App starts with zero required configuration
- [ ] `_FILE` pattern for SMTP_PASSWORD, GOTIFY_TOKEN, etc.
- [ ] Optional basic auth middleware, off by default, controlled by env var
- [ ] `BINOCULAR_DB_PATH` configurable
- [ ] `.env.example` documents all env vars with defaults
- [ ] `backend/src/binocular/auth.py` implements optional basic auth
- [ ] `backend/src/binocular/utils/masking.py` masks secrets in logs
